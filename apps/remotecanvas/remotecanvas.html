Remote Canvas

Any device on the network can POST JSON to this app to draw on the __WIDTH__x__HEIGHT__ matrix. Base URL: http://__IP__/

Set background

Fills the whole display with one color.

POST/background
{
  "color": "#003366"
}

Draw pixel

POST/pixel
{
  "x": 5,
  "y": 5,
  "color": "#ffffff"
}

Draw line

POST/line
{
  "x0": 2,
  "y0": 2,
  "x1": 20,
  "y1": 10,
  "color": "#ffffff"
}

Draw rect

Coordinates are inclusive pixel positions. Include either or both colors.

POST/rect
{
  "x0": 2,
  "y0": 2,
  "x1": 20,
  "y1": 10,
  "border_color": "#ffffff",
  "fill_color": "#ff0000"
}

Draw circle

x/y is the center. Include either or both colors.

POST/circle
{
  "x": 16,
  "y": 16,
  "radius": 8,
  "border_color": "#ffffff",
  "fill_color": "#ff0000"
}

Draw text

font_size is one of "mini", "small", "large". Give x/y for an exact position, or align/valign with an optional padding (ignored on "center").

POST/text
{
  "text": "Hello",
  "font_size": "small",
  "color": "#ffffff",
  "align": "center",
  "valign": "center"
}

Display info

GET/info
{
  "width": __WIDTH__,
  "height": __HEIGHT__
}
